# Workflow: Outreach Drafting & G2 Request

```yaml
agents: Outreach-Drafter, Proof-Builder
governance: .agents/rules/02-approval-gates.md
```

## Steps
1. **Retrieve Qualified Prospect:** Select verified prospect from `Prospect Tracker`.
2. **Retrieve Proof Asset:** Obtain labeled preview/audit asset generated by `Proof-Builder`.
3. **Draft Outreach Message:**
   - Reference exact factual observation (e.g. "Noticeable page load bottleneck on mobile menu").
   - State sender identity accurately (Tom Gronek's team).
   - Provide clear, simple value preview asset link.
   - Include soft, no-pressure call to action.
   - Include clear opt-out sentence ("If you'd prefer not to receive updates, simply reply 'stop'").
4. **Prepare G2 Approval Request:** Return structured Change Packet to `Atlas-Orchestrator` requesting G2 approval:
   - Recipient List
   - Outreach Channel
   - Message Body
   - Batch Size
   - Sending Window
