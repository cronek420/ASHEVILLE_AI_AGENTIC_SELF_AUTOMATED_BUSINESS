# Validate a Project

1. Confirm the approved scope and expected files.
2. Run the project's relevant syntax, test, lint, type-check, build, and safe smoke checks.
3. Check internal links, configuration references, duplicate governing rules, secret exposure, and unresolved placeholders.
4. Record exact results and limits in `BUILD_STATUS.md` and `SESSION_HANDOFF.md`.
5. Do not claim completion when checks were not run or cannot validate the requested behavior.
