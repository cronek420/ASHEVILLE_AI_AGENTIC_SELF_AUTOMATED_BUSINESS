# Project AI Instructions

Read in this order:

1. `.agents/rules/00-project-governance.md`
2. `PROJECT_ONBOARDING.md`
3. `PROJECT_CONTEXT.md`, `PROJECT_REQUIREMENTS.md`, and `DECISIONS.md`
4. `NEED_HUMAN_APPROVAL` for all pending human decisions, risks, costs, and external-action approvals
5. `.agents/agent.md`
6. The relevant workflow and selected skills
7. `SESSION_HANDOFF.md`

For a new project, run `.agents/workflows/start-new-project.md` before implementation.
